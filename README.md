# Academia Barros — Taekwondo e Fitness

Site estático em HTML, CSS e JavaScript baseado no layout fornecido.

## Estrutura

```text
academia-barros-site/
├── index.html
├── style.css
├── script.js
└── assets/
    ├── logo.png
    ├── hero-musculacao.jpg
    ├── hero-taekwondo.jpg
    ├── galeria-1.jpg
    ├── galeria-2.jpg
    ├── galeria-3.jpg
    └── galeria-4.jpg
```

## Como publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css`, `script.js` e a pasta `assets`.
3. Entre em **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`.
6. Salve e aguarde o GitHub gerar o endereço do site.

## Importante

Substitua os arquivos dentro de `assets` pelas fotos e pela logo reais da Academia Barros, mantendo os mesmos nomes dos arquivos.

No `index.html`, o mapa usa uma pesquisa genérica por "Academia Barros". Para mostrar o endereço correto, substitua o `src` do iframe pelo código de incorporação fornecido pelo Google Maps.
